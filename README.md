# Next.js App Router Starter

A production-ready Next.js App Router starter template designed for AI coding agents. Build modern web applications faster with Cursor, Claude, GitHub Copilot, Google Gemini, and other AI assistants.

## 🚀 What Is This?

This is a **DevSpec pack** — a complete starter template that includes not just code, but comprehensive specifications and documentation designed to help AI coding agents understand your project and build features efficiently.

### Key Features

- ⚡ **Next.js 15** with App Router
- 🎯 **TypeScript** for type safety
- 🎨 **Tailwind CSS** for styling
- 📝 **DEVSPEC.md** — Complete build specifications for AI agents
- 🤖 **SKILL.md** — Agent-specific instructions and workflows
- 🧪 **Ready to build** — All configurations pre-set
- 📦 **Minimal yet complete** — Everything you need, nothing you don't

## 🏗️ How to Use

### 1. Clone or Use This Template

```bash
# Clone the repository
git clone https://github.com/hacodesolutions/nextjs-app-router-starter.git
cd nextjs-app-router-starter

# Or use as template on GitHub
# Click "Use this template" button
```

### 2. Install Dependencies

```bash
npm install
# or
yarn install
# or
pnpm install
```

### 3. Set Up Environment Variables

```bash
cp .env.example .env.local
# Edit .env.local with your configuration
```

### 4. Start Development

```bash
npm run dev
# Open http://localhost:3000
```

### 5. Work with AI Agents

Give your AI agent these files to understand your project:

- **DEVSPEC.md** — Complete project specifications
- **SKILL.md** — Agent-specific workflow instructions

Example prompts:

```
"Read DEVSPEC.md and add a new feature for user authentication"
"Following SKILL.md, create a blog posts listing page"
"Add a contact form component with validation"
```

## 🎯 DevSpec Methodology

This project follows the **DevSpec** approach:

1. **Specifications First** — Complete documentation before coding
2. **AI-Readable** — Structured markdown for agent comprehension
3. **Step-by-Step** — Clear instructions and acceptance criteria
4. **Environment-Aware** — Includes all setup and configuration details
5. **Testable** — Defined success metrics and validation steps

## 💡 Why DevSpec?

Traditional starters give you code. **DevSpec packs** give you:

- Complete specifications AI agents can follow
- Step-by-step instructions for adding features
- Acceptance criteria for validation
- Architecture documentation
- Best practices and patterns
- Testing guidelines

This means you spend less time explaining to your AI agent and more time building.
